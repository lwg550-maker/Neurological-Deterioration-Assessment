# Browser calculator

Open `index.html` in a modern browser or use the GitHub Pages deployment at:

https://lwg550-maker.github.io/Neurological-Deterioration-Assessment/

The calculator is a self-contained research-use prototype. It performs all feature engineering and frozen M1 inference locally in the browser and contains no request to an external server. The alert comparison uses the exact threshold `0.028094640664533963`; `0.0281` is display rounding only.

Entered observations must already meet the study's Tier C, timing, validity, sedation, and availability rules. Do not enter identifiable data into a public or shared computer. The tool has not been prospectively validated and does not direct CT, medication, EVD, surgery, or other treatment.
